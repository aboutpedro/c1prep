Grammar

Conditionals and alternatives to if

Each set has 10 sentences. Follow the instructions above the sentences, then press Check answers.

C2 conditionals mix time frames, drop if in favour of inversion, and use a range of alternatives (but for, provided, supposing, otherwise).

Mixed conditionals

  • If I had worked harder, I’d have a better job now.past condition → present result
  • If she weren’t so stubborn, she wouldn’t have made that mistake.present situation → past result

Inversion instead of if

Had we known…= If we had known…
Were I in your position…= If I were…
Should you need help…= If you need help (formal, less likely)
Had it not been for / Were it not for your help…= If it hadn’t been / weren’t for…

Careful: negatives don’t contract in inverted conditionals: Had it not been for… (not Hadn’t it been for).

Alternatives to if

  • Provided / Providing (that), as / so long as, on condition thatonly if
  • But for your help… · Without your help…+ noun
  • Supposing / Suppose you lost your job…imagine
  • Unless you hurry… · Hurry, otherwise we’ll be late.if not
  • In case it rains… · In the event that… · In case of fire…
  • If so / If not · Given more time, we could…
