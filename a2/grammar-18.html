Grammar

Irregular verbs in the past simple

Each set has 10 sentences. Follow the instructions above the sentences, then press Check answers.

Regular verbs add -ed in the past: worked, played. Irregular verbs don’t follow a rule, so the best way is to learn them in groups that sound the same.

The most common ones

be → was / werego → wenthave → had
do → didsay → saidget → got
make → madesee → sawcome → came
take → tookgive → gaveknow → knew

Groups that sound the same

-ought / -aughtbuy → bought · think → thought · bring → brought · fight → fought · teach → taught · catch → caught
-ewfly → flew · know → knew · grow → grew · throw → threw · blow → blew
i → adrink → drank · sing → sang · swim → swam · begin → began · sit → sat
o_ewrite → wrote · ride → rode · drive → drove · wake → woke
-tfeel → felt · sleep → slept · leave → left · meet → met · send → sent · spend → spent
no changecut · put · cost · hit · hurt · let · set · shut · read (but we say “red”)

Careful: with didn’t and did, go back to the normal verb: I didn’t go. Where did you buy it? (not didn’t went, did you bought).
