Grammar

Conditionals

Each set has 10 sentences. Follow the instructions above the sentences, then press Check answers.

Conditionals link a condition (the if part) to its result. At B2 you need all four main types, mixed conditionals, and the other words that can replace if.

The four main conditionals

if partresult
zeropresent: If you press this,present: it switches off.
firstpresent: If it rains,will + verb: we’ll stay in.
secondpast: If I had time,would + verb: I’d learn the guitar.
thirdpast perfect: If we’d left earlier,would have + past participle: we wouldn’t have missed it.

You might also see

  • If I were you, I’d apologise.advice; were for all persons
  • We might have won if Sam hadn’t been injured.might / could have = a possible result

Careful: no will or would in the if part: If it rains, If I had known.

The third conditional

It imagines a different past, so it’s used for regrets, criticism and relief.

  • If you’d told me, I’d have come.In the if part, ’d = had. In the result, ’d = would.
  • What would you have done if you’d missed the last bus?

Mixed conditionals

The time of the condition and the time of the result can be different.

past → nowif + past perfect, would + verb: If I had studied medicine, I’d be a doctor now.
always → pastif + past simple, would have + past participle: If he spoke French, he’d have got the job.

The second type describes a general fact about someone (he doesn’t speak French) and its result in the past.

Other words instead of if

unlessif … not: You won’t pass unless you study.
as long as / provided (that) / on condition thatonly if: You can borrow it as long as you bring it back.
in caseto be ready for something that might happen: Take cash in case they don’t take cards.
even ifit makes no difference: We’ll go even if it rains.
otherwiseif not, or else: Hurry, otherwise we’ll be late.

Careful: in case is not the same as if. Take an umbrella in case it rains = take it now. Take an umbrella if it rains = only take it if it’s raining.
