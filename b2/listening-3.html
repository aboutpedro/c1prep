Listening · Part 3

Multiple matching

You will hear five short extracts in which people are talking about moving to a new city. For questions 19–23, choose from the list (A–H) what each speaker says about the experience. Use the letters only once. There are three extra letters which you do not need to use.

Five people talk about the same subject. You choose what each one says from a list. You hear the five speakers twice.

How to do it

  1. Read the options first and think of other ways of saying each one.
  2. On the first listening, note a possible letter for each speaker.
  3. On the second listening, check your choices: what exactly does each speaker say that matches?
  4. Each letter can be used only once, and some letters are not used at all.

Watch out for

  • Speakers often mention the ideas in other options too. The answer is the idea the speaker's point is really about.
  • Don't choose an option just because a speaker uses one of its words.

In the B2 First exam, the Listening paper takes about 40 minutes, and you hear every recording twice. You can replay recordings here, but try each set the exam way first.
