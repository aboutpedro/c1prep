Grammar

Conditionals

Each set has 10 sentences. Follow the instructions above the sentences, then press Check answers.

Conditional sentences talk about a situation (the if part) and its result. Which conditional you use depends on how real the situation is: always true, a real possibility, or imaginary.

From real to imaginary

if partresultuse
zeroif + presentpresentthings that are always true
firstif + presentwill + verba real possibility in the future
secondif + pastwould + verbimaginary or unlikely situations

The if part can come first or second. When it comes first, use a comma: If it rains, we’ll stay in. / We’ll stay in if it rains.

Zero and first conditionals

The basics

  • If you heat ice, it melts.
  • If I drink coffee late, I can’t sleep.
  • If it rains tomorrow, we’ll stay at home.
  • If you don’t hurry, you’ll miss the bus.

You might also see

  • If you see Tom, tell him to call me.An instruction in the result.
  • If you’re tired, you can go to bed.

Careful: no will in the if part, even though it’s about the future: If it rains, not If it will rain.

Second conditional

The past form here doesn’t mean past time. It shows that the situation is imaginary, or very unlikely.

The basics

  • If I had more time, I’d learn the guitar.
  • What would you do if you won the lottery?
  • If I were you, I’d take the job.Giving advice. Were is used with all persons; was is also common in speech.

You might also see

  • If I get the job, I’ll move to Lisbon. / If I got the job, I’d move to Lisbon.The first is a real plan; the second sounds unlikely to the speaker.
  • We could go to the beach if the weather was better.Could and might can replace would.
  • I’d be surprised if she didn’t come.

unless, when, as soon as, in case

These words work like if: they’re followed by a present tense even when we mean the future.

wordmeaningexample
unlessif … notYou won’t pass unless you study.
whenit will definitely happenI’ll call you when I get home.
as soon asimmediately afterI’ll text you as soon as I land.
in caseto be ready if something happensTake an umbrella in case it rains.

Careful: compare I’ll call you if I get the job (maybe I won’t) and I’ll call you when I get home (I’m sure I will).
