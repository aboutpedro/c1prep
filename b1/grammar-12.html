Third conditional and wishes

Each set has 10 sentences. Follow the instructions above the sentences, then press Check answers.

Sometimes we imagine a different past: If I had left earlier, I wouldn’t have missed the bus. We also use wish and if only to say we’d like things to be different, now or in the past.

The third conditional

if parthad + past participle: If I had known…
resultwould have + past participle: …I would have helped.

It talks about something that didn’t happen, and its imaginary result. It’s often used for regrets and criticism.

The basics

  • If you had told me, I would have come.You didn’t tell me, so I didn’t come.
  • We wouldn’t have got lost if we had had a map.

You might also see

  • If I’d known, I’d have called you.In the if part, ’d = had. In the result, ’d = would.
  • What would you have done if you hadn’t got the job?
  • If I hadn’t missed the bus, I might have got the job.might / could have = a possible result

Careful: no would in the if part: If I had known, not If I would have known.

Which conditional?

zeroalways true: If you heat ice, it melts.
firstreal possibility: If it rains, we’ll stay in.
secondimaginary now / future: If I won the lottery, I’d buy a boat.
thirdimaginary past: If I had won, I’d have bought a boat.

wish and if only

Move the verb one step back into the past, just like in conditionals.

about nowwish + past simple: I wish I had a car. I wish I could swim.
about the pastwish + had + past participle: I wish I had listened to you.
annoying behaviourwish + would: I wish you would stop talking!

You might also see

  • If only I knew the answer!If only is stronger than I wish.
  • I wish I were taller.After wish and if, were is common for all persons; was is also fine in conversation.
  • I wish I didn’t have to work tomorrow.
